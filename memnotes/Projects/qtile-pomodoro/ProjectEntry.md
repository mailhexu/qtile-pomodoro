# qtile-pomodoro

## Overview
A Qtile-specific X11 Pomodoro timer with persistent local state, a bar widget, and all-screen break overlays.

## Tech Stack
- Python 3.11+
- Qtile 0.37 on X11
- SQLite and TOML from the Python standard library
